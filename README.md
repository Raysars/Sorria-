# Sorriaê

Guia digital de saúde bucal infantil para pais e responsáveis, com orientação clara sobre cuidados com a infância, escovação, creme dental com flúor, alimentação e procedimentos em caso de trauma dentário.

## Sobre o projeto

Este projeto é uma página web estática inspirada no guia "Sorriaê", com foco em:

- fases da infância e cuidados específicos para cada idade;
- uso correto de creme dental com flúor;
- instruções práticas de escovação;
- dicas sobre alimentação para proteção dos dentes;
- orientações rápidas para primeiros socorros em casos de trauma dentário.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Assets locais em pasta `assets/`

## Observação

Este projeto foi desenvolvido como material informativo e de apoio educativo. Em casos de dúvidas ou emergência odontológica, é importante buscar orientação de um dentista ou profissional de saúde capacitado.
